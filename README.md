# Mis-Proyectos

Ejercicios de clase que retomo y mejoro por mi cuenta, con funcionalidades extra y experimentos.

## 🕐 Reloj mundial

Reloj analógico dibujado con JavaScript que muestra la hora de distintos países. Eliges el país en un desplegable y el reloj se actualiza en tiempo real con su zona horaria.

▶️ **Demo:** https://aymanmzkk.github.io/Mis-Proyectos/reloj-mundial.html

**Tecnologías:** HTML · CSS · JavaScript (API `Intl` para las zonas horarias)
